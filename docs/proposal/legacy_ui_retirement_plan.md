- 状态：实施中 / 本地 dev 阶段检查点

- 适用范围：移除 Classic 和旧 Dragon，保留 Dragon Next 为唯一维护的 WebUI

## 目标与边界

完成后，仓库只维护 `web/frontend-next/` 一套前端源码；继续使用现有 aiohttp API、训练服务及用户数据。
旧界面源码通过 Git 历史保留，不在活跃源码树内复制一套归档。`/next` 路径暂时保持，路径改名另行安排。

本计划涵盖依赖迁移、功能对账、入口收拢、旧资产及测试清理、部署说明和退役验收。
不包含界面重新设计、训练内核重构、新增模型能力，也不迁移或清理模型、配置、数据集、缓存、队列、历史和输出。

## 1. 背景与目标

一句话：把「多数据集 / 分辨率 / 阶段」的责任交给用户，并把数据集页收成清晰主路径。

### 1.1 产品意图

用户自主：

1. 配置多个数据集行（可同源路径）
2. 为每行设定分辨率与缓存相关参数
3. 配置不同数据集在训练进度中的使用阶段

示例心智（底层仍落为全局 %）：

```text
总预算按 max_train_steps 计
0–30%  → 数据集@512
30–60% → 数据集@768
60–100%→ 数据集@1024
```

前提：**各阶段所需缓存已在预处理阶段生成**。训练中只切换 subset 索引，不重做 VAE/TE/PE 编码。

### 1.2 目标

- 数据集页成为多数据集配置主战场
- 主卡只保留高频字段
- 实验性与分阶段均为弹窗，入口在顶栏同一行
- 阶段数 N、数据集数 M 均可变；默认 2 段；三阶段只是模板
- 不改训练引擎数据模型语义：`stage_schedule[]` 仍属训练配置

### 1.3 非目标

- 不把 `stage_schedule` 迁入数据集预设文件
- 不做「每段本地 epoch 配额」引擎
- 不在训练中途跑完整预处理
- 不重做整个数据集预设系统
- 不写死 3 段 / 3 数据集槽位

## 2. 已锁定决策

| 决策 | 选择 |
|---|---|
| 实验性弹窗范围 | 只编辑**当前选中**的那一集 |
| 双入口位置 | 数据集页**顶栏 / 预设工具条同一行** |
| 主卡密度 | **精简档** |
| 阶段时间语言 | **全局进度 %** |
| 课表存储归属 | 仍在**训练配置 TOML**（`stage_schedule*`） |
| 热切换策略 | 预处理完成后按 % 切；开销可接受 |
| 默认段数 | 2（最低有意义 curriculum） |
| 最少 / 最多段 | 最少 1；软上限 8–12 |

## 3. 信息架构

一句话：列表管「料」，顶栏管「附加能力」，课表跨集、实验性单集。

```text
数据集页
├─ 左：预设列表（沿用）
└─ 右：编辑区
   ├─ 顶栏工具条（同一行）
   │   [实验性/高级] [分阶段调度] [+ 添加数据集] [预览…]
   ├─ 数据集卡片列表（点击选中 = 当前集）
   │   主卡常驻高频字段
   └─ 弹窗
       ├─ 实验性：仅当前选中集
       └─ 分阶段：当前训练配置的 stages[] 课表

训练配置页
└─ 分阶段：只读摘要 + 去编辑（打开同一套弹窗 / 引导至数据集页）
```

### 3.1 职责边界

| 对象 | 管什么 | 不管什么 |
|---|---|---|
| 数据集行 | 路径、分辨率、桶策略、标注、验证、缓存相关 | 全局训练进度如何切 |
| 分阶段课表 | 何时用哪一行（% 区间 + subset 引用） | 分辨率数字本身 |
| 实验性弹窗 | 当前集低频/旧字段 | 其他集、课表结构 |
| 训练引擎 | 按 progress 选 active subset 并重建索引 | UI 布局 |

产品口径：

> 阶段绑的是「数据集行」，不是「分辨率数字」。  
> 要两种分辨率 = 至少两行数据集配置（可同源路径，不同 resolution/cache）。

---

## 4. 数据模型

一句话：列表，不是固定槽位。

### 4.1 阶段表（训练配置）

```text
stage_schedule_enabled: bool
stage_schedule: [
  { name, subset_index, start_pct, end_pct },  // 0..N-1
  ...
]
```

说明：

- `start_pct` / `end_pct` 存储为 `[0, 1]` fraction；UI 可显示 0–100
- 进度语义：`[start, end)`，最后一段包含 100%
- 字段名保持 `subset_index`（不改为 `dataset_ref`）；文档可称「数据集行引用」
- **没有** `stage1/stage2/stage3` 固定字段

### 4.2 约束

| 约束 | 规则 |
|---|---|
| N ≥ 1 | 1 段 = 等价全程单集（可提示直接关闭分阶段） |
| N 任意 | 2/3/5… 同一套 UI |
| M 与 N | 不必相等；可复用同一 subset；下拉来自当前预设全部行 |
| 覆盖 | 强制 `0% → 100%`，无空洞、相邻贴齐 |
| 分辨率递增 | 不强制；后段分辨率 < 前段时可选 warning |

### 4.3 数据集行（预设）

沿用现有 subset/row 结构。分辨率、路径、cache 等在行上配置。  
分阶段只引用行索引，不复制分辨率。

## 5. UI 规格

### 5.1 主数据集卡片（精简）

**常驻：**

- 原始路径
- 分辨率
- 分桶开关
- 重复次数
- 标注来源
- 验证比例
- 标题徽章 / 删除 / 预览入口

**进入实验性弹窗：**

- 最小/最大桶边、桶步长
- 禁止放大等桶策略细节
- 固定验证数量、验证种子
- 现有「实验性/高级/旧功能」字段
- 其他低频项

交互：

- 点击卡片设为当前选中集（高亮）
- 主卡**不**放分阶段主按钮
- 实验性主入口在顶栏；可选在卡上保留次要「高级」入口，但不得形成第二套字段编辑器

### 5.2 实验性弹窗

| 项 | 规则 |
|---|---|
| 打开条件 | 已选中某一数据集 |
| 无选中 | 按钮禁用或提示「先点选一个数据集」 |
| 标题 | `实验性 · SUBSET N · {resolution}px` |
| 范围 | 只改这一集 |
| 写回 | 更新该行 draft；保存仍走预设保存按钮 |

### 5.3 分阶段弹窗

| 项 | 规则 |
|---|---|
| 数据源 | `draftValues || currentConfig` 的 `stage_schedule*` |
| 结构 | 启用开关 + 动态色带 + 动态表 + 当前段编辑 |
| 渲染 | `stages.map(...)`，段数变只改数组长度 |
| 颜色 | `palette[i % palette.length]` |
| 窄段 | 条内可只显示分辨率数字；hover 显示全名（P2） |
| 默认 | 启用时若空表，给 2 段模板 `0–50 / 50–100` |
| 模板 | 两段、三段、均分当前 N；清空为 1 段可选 |
| 加段 | 劈最后一段为两半 |
| 删段 | 最少 1；删到 1 时提示可关闭分阶段 |
| 上下移 | 允许；需保持合法覆盖（可重贴齐或均分，实现时选一种并测稳） |
| 下拉 | 当前预设全部数据集行；可复用 |
| 下拉为空 | 禁用启用或明确提示先配数据集 |
| 应用 | 写入训练配置 draft；有 error 则拦截 |

### 5.4 色带与两段体验

2 段是一等公民：

```text
0% ──────── 40% ──────── 100%
████ 512/集A   ████████ 1024/集B
```

摘要示例：

```text
分阶段 · 2 段 · 512→1024 · 0–40% / 40–100%
```

训练侧展示（P2）：

```text
阶段 1/2 · subset#0 · 512 · 下一切换 40%
```

### 5.5 训练配置页

- 不再作为课表主编辑面
- 保留只读摘要 +「编辑课表」打开同一实现
- 避免第二套可写 UI 造成状态分叉

## 6. 校验

启用分阶段时（与 N 无关）：

1. `start_0 = 0`，`end_{N-1} = 1.0`
2. 相邻贴齐：`end_i == start_{i+1}`（容差按现有 1e-6）
3. 每段区间非空
4. 每段 `subset_index` 在当前数据集行范围内
5. `max_train_steps` 已锁定且 > 0（有分阶段时优先步数，不靠含糊 epoch）
6. 尽量提示各段缓存/预处理状态（能检则 ✓/✗；不能检则文案前提）
7. 可选 warning：后段分辨率 < 前段

规则：

- **error** 阻止应用到草稿 / 开训
- **warning** 可保存
- **不校验**必须 3 段、必须 3 数据集、必须分辨率递增

## 7. 运行时与预处理

### 7.1 热切换开销结论

在缓存已预生成前提下，阶段切换当前实现只做：

- 从全量 snapshot 过滤 subset
- 重建 bucket 索引
- 重建 DataLoader（关闭 persistent_workers 以免脏长度）

**不做** VAE/TE/PE 重编码。  
因此开销可接受，**按 % 直接切**，不另起重算体系。

### 7.2 总步数

- 硬边界：`max_train_steps`
- 有分阶段时：UI/bootstrap 明确要求或强烈提示锁定总步数
- `max_train_epochs` 单独换算 steps 时，长度随当前 active 集变化，语义含糊；本设计不把它当主输入
- 本阶段不做「名义总 epoch 区间 → %」糖（可列 P3）

### 7.3 预处理前提

推荐流水线：

```text
建多数据集行（不同 resolution/cache）
  → 预处理每行缓存
  → 配置 stages[]
  → 开训前校验
  → 训练中按 progress 热切
```

## 8. 状态流

```text
数据集预设 rows ──主卡/实验性──► 预设 draft ──保存──► 预设文件
       │
       └──── 下拉选项 ────► 分阶段弹窗
                              │
当前训练配置 ◄── hydrate ─────┘
       │
       └─ apply stage payload ──► config draft ──保存──► 训练 TOML
                                      │
                                      └─ 启动训练 ──► stage_schedule 解析/校验/切换
```

约束：

- 分阶段弹窗每次打开 re-hydrate，防止换配置串台
- 前端「当前选中集」不落盘
- 单一真相源：训练配置上的 `stage_schedule*`

## 10. 分期交付

| 期 | 内容 | 验收 |
|---|---|---|
| **P0** | 顶栏双入口；实验性弹窗（当前集）；分阶段主编辑迁数据集页；配置页只读摘要 | 可配 2 段并写入训练配置草稿 ✅ 已落地 |
| **P1** | 主卡精简（字段搬家，键名不变） | 主路径明显变短；旧字段不丢 ✅ 已落地 |
| **P2** | 摘要增强、分辨率递减 warning、缓存提示、监控文案、窄段 hover | 产品完整度 |
| **P3** | 名义 EP 区间 UI 糖、更强缓存探测 | 可选 |

实现约束：

- 优先拆模块，避免继续堆热点大文件
- 新增 UI 逻辑按 feature / state / renderer 分
- 不顺手改无关训练算法

## 12. 成功标准

1. 用户可自建多数据集、自定分辨率、自定 N 段 % 课表  
2. 两段是一等公民，不是残缺模式  
3. 三阶段只是模板，不是骨架  
4. 预处理完成后训练按 % 热切，无重编码  
5. 主列表明显变短；实验性/课表不挡主路径  
6. 旧配置可加载保存，无强制迁移  
7. 训练配置页不再维护第二套可写课表编辑器

## 13. 实现侧一句话

```text
UI: stages.map(...) 渲染色带 + 表行
存储: 训练配置 stage_schedule 数组
调度: 找 start_pct <= progress < end_pct 的段（末段含 100%）
页面: 数据集顶栏双弹窗；主卡精简；实验性=当前集
```
